# Power

Tools and measurements for reproducible LLM inference power benchmarking on AMD Instinct accelerators.

## Platforms

- [MI300X](mi300x/README.md) — vLLM workload runner, AMD GPU power telemetry, scenario configurations, analysis tools, and example GPT-OSS-120B results.

Benchmark result directories are intentionally excluded from Git. Publish reviewed result summaries and figures rather than transient or partial raw runs.
